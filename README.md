# TravelCargo — Shipping Made Simple

A peer-to-peer package shipping landing platform redesign connecting verified travelers with package senders.

## ✨ Features

- **Authoritative Vanilla Design System**:
  - Background: `#FFF9EB` (Warm Vanilla)
  - Text: `#200f07` (Midnight Black)
  - Primary Accent: `#c5e384` (Pistachio Green)
  - Secondary Accent: `#c4dae8` (Soft Blue)
- **Typographic Hierarchy**:
  - Wordmark / Headline: `Helvetica Neue Bold`
  - Tagline: `Instrument Serif` with emphasized, pronounced italic and underline on *"simple."*
- **Immersive 3D Doodle Globe**:
  - Geographically accurate continent coastlines (Eurasia, Japan, British Isles, Africa, Americas, Australia).
  - Great Circle 3D flight arcs connecting real-world landmasses with smooth continuous 60fps gliding planes.
  - Solid linework with sweeping horizon perspective peeking in from the bottom-right corner.
- **Interactive Components**:
  - **Send a Package**: Box lid opens on hover with an upward confetti particle burst + interactive cost & carbon savings calculator modal.
  - **Register a Trip**: Airplane take-off and loop-back fly-out hover animation + traveler earnings estimator modal.
  - **Live Match Ticker**: Compact, fully rounded pill badge displaying real-time matched routes (`Berlin → Mumbai`, etc.).

## 🚀 Running Locally

You can run this project locally with any static file server:

```bash
# Python
python -m http.server 4173

# Or Node / npx
npx serve .
```

Open `http://localhost:4173` in your browser.
